## 第一版行为

- 单人模式；多人或非主玩家明确拒绝。
- 默认 8 个分身，允许 1–12 个；同一时间一个剑阵。
- 环绕约 0.9 秒，展开约 0.6 秒，再分批向附近怪物发射。
- 预览只射向空中，不扣技能体力、不伤害怪物。
- 实战使用已有战斗解锁和形态门槛，消耗 1 点技能体力；取消或未命中不返还。
- 冷却 8 秒，最大存活 12 秒。按 Esc 本地立即取消；换地图、菜单、事件、死亡、断开连接也会中止。
- 碰撞确认后调用游戏伤害 API；统计真实血量下降，不把动画完成当作击杀成功。
- 检查建筑层阻挡，但不声称具备完整寻路或所有地形阻挡支持。
- 重复请求不重复消费；创建响应丢失会发出同一操作 ID 的取消请求。
