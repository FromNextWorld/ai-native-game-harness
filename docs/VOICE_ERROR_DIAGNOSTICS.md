# 语音故障诊断

玩家提示简短，不等于丢弃技术错误。每次捕获的异常在转成玩家文案或执行降级前，写入独立诊断。

## 保存位置与关联

- `${DSH_HOME}/diagnostics/errors-YYYY-MM-DD.jsonl`；未设置 DSH_HOME 时使用用户目录 `.dsh/diagnostics`。
- 日期使用 UTC。按日分文件、追加写入并 flush，不自动删除旧文件。
- 每行包含时间、错误编号、失败阶段及已知的游戏/进程/录音/交互/会话/模型标识。
- 同一个 Error 跨层传播保留同一个 errorId，各层追加自己的上下文，不用笼统的 `asr-or-agent` 代替内部阶段。
- 游戏失败提示附带编号前八位；日志保存完整 UUID，可检索此前缀。
- stdout 同时输出 `AI_GAME_HARNESS_ERROR`，供桌面运行日志收集。

## 信息边界

保存 message、stack、code、HTTP status、上游请求编号、cause 和 AggregateError 子错误。循环引用、超过 32 层的异常链会明确标记，不能无提示截断。

不复制 request/response、headers、对话、原始音频、截图或思考内容。常见密钥格式、授权字段和环境变量中的密钥值脱敏。第三方异常 message 可能自带业务内容，向外分享日志前仍需复核；日志完整不意味着明文保存凭据。

覆盖媒体事件、ASR 流启动/完成与降级、视觉准备、会话初始化/恢复、模型回复（含返回部分文本的降级）、TTS、Gateway RPC 和 Adapter 动作失败。

## 存储失败与验证

落盘失败必须输出 `AI_GAME_HARNESS_LOG_WRITE_FAILED`，并仍尝试 stdout 记录原异常。stdout 失败仍保留独立文件。日志设施不能把原本可恢复的错误变成新的业务失败。

自动测试验证完整 JSONL、追加保留、跨层编号、原始 cause/堆栈、脱敏、断管道与磁盘路径不可写，以及语音失败提示的编号接线。

这不是断电、磁盘损坏、两路日志同时失效或进程被强杀时的绝对完整保证；也不能恢复此前已经丢弃的错误。未捕获的进程级故障仍需桌面 Runtime 日志。本改动不证明“万剑归宗”执行故障已修复，需安装后真实复现定位。

## 游戏重连会话修复

`7545e7da` 的实际堆栈确认：失败发生在 `waitForSessionRelease`，尚未调用模型或技能。原检查把任何已注册 Agent/Session 都视为“正在释放”，而 Desktop 通用会话解析器也可能先恢复同一普通 Session。

- 新连接通过同一 Cordis root 下按 Session ID 共享的租约串行交接。只调用自己持有的 AgentHandle disposer，不直接删除 SDK 注册表或磁盘数据。
- 已由 Desktop 恢复的普通 Agent：等待空闲后借用，在可撤销子 fiber 中安装游戏策略、模型选择、输出限制与技能；断开仅清理自己的绑定，不销毁外部所有者的 Agent。
- 旧连接被替代后失效，迟到的关闭不能释放新租约；断连后的排队消息不再执行。
- 初始化未结束就断开：AbortSignal 阻止后续发布，已返回的资源回滚；初始化 flush 失败也清理本次句柄。
- 仅 SDK 明确报告该 Session 不存在才创建。网络、鉴权、损坏、挂载异常保留原始故障，不用空会话掩盖。
- 不把仍运行的外部 Agent 强行当作空闲；等待可以被连接关闭取消。无 Agent 的异常挂载、释放失败则明确报错，不越权删除。
- 生命周期 `ready` / `borrowed-live-agent` 输出至运行日志，失败仍进入独立 JSONL。
